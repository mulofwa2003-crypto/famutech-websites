# FAMUTECH Version 2
Responsive FAMUTECH Electrical & Solar Solutions site with editable content, quote-to-WhatsApp flow and protected admin dashboard.

Run:
1. Install Node.js 20+
2. npm install
3. Configure environment variables
4. npm start
5. Open http://localhost:3000
6. Admin: http://localhost:3000/admin

Demo fallback login (CHANGE BEFORE PRODUCTION):
admin@famutech.com
ChangeMe123!

For production use HTTPS, a persistent database, a strong SESSION_SECRET, a real ADMIN_PASSWORD_HASH, 2FA, CSRF protection, audit logs and backups.
